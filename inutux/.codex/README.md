# Codex Suite

Suite profesional de agentes para desarrollo de software.

## Objetivo

Proporcionar un conjunto de agentes especializados para analizar, desarrollar, revisar, documentar y mantener cualquier proyecto.

## Flujo de trabajo

Project Manager
↓
Codebase Mapper
↓
Architecture Reviewer
↓
Especialista correspondiente
↓
QA Engineer
↓
Security Auditor
↓
Documentation Writer
↓
Release Manager

## Reglas generales

- Analizar antes de modificar.
- Nunca romper compatibilidad.
- Mantener código limpio.
- Documentar cambios importantes.
- Trabajar siempre en español.
- Evitar duplicación de código.
- Revisar dependencias antes de implementar.
