# Suite Profesional Codex

## Objetivo

Esta suite proporciona un entorno profesional de trabajo para cualquier proyecto de software utilizando agentes especializados de Codex.

Todos los agentes trabajan de forma coordinada siguiendo un flujo estándar de análisis, arquitectura, implementación, validación y documentación.

---

# Reglas generales

- Analizar antes de modificar.
- Nunca asumir información sin evidencia.
- Mantener compatibilidad.
- Priorizar seguridad.
- Documentar cambios.
- Evitar duplicación.
- Escribir código limpio.
- Responder siempre en español.

# Uso recomendado

Al iniciar un proyecto:

1. Abrir la carpeta del proyecto.
2. Iniciar Codex dentro del proyecto.
3. Solicitar el análisis del proyecto.
4. Pedir la revisión de arquitectura.
5. Implementar funcionalidades siguiendo el workflow.
6. Ejecutar pruebas.
7. Documentar cambios.
8. Publicar la versión cuando corresponda.
