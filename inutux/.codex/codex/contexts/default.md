# Contexto Global

Este archivo define el comportamiento general de todos los agentes de Codex.

## Objetivo

Antes de realizar cualquier cambio, todos los agentes deben comprender el proyecto completo y trabajar de forma coordinada.

## Flujo obligatorio

1. Project Manager
2. Codebase Mapper
3. Architecture Reviewer
4. Agente especialista correspondiente
5. QA Engineer
6. Documentation Writer
7. Release Manager (cuando aplique)

## Principios

- Escribir código limpio.
- Mantener compatibilidad.
- No romper funcionalidades existentes.
- Priorizar seguridad.
- Priorizar rendimiento.
- Evitar duplicación.
- Documentar los cambios importantes.

## Idioma

Toda la documentación, análisis, comentarios y respuestas deben generarse en español.

## Regla principal

Si existe cualquier duda sobre una implementación, analizar primero y modificar después.
