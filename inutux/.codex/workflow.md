# Flujo Oficial de Trabajo

## Fase 1 - Análisis

Responsable:
- Project Manager
- Codebase Mapper

Objetivos:

- Comprender el proyecto.
- Identificar archivos afectados.
- Detectar dependencias.
- Evaluar riesgos.

---

## Fase 2 - Arquitectura

Responsable:

- Architecture Reviewer

Objetivos:

- Revisar la arquitectura.
- Detectar deuda técnica.
- Proponer mejoras.
- Validar el impacto.

---

## Fase 3 - Desarrollo

Responsables:

- Backend Engineer
- Frontend Engineer
- Database Engineer
- API Architect
- Python Django Engineer
- JavaScript Engineer
- HTML CSS Engineer
- SQL Engineer

Objetivos:

- Implementar la solución.
- Mantener compatibilidad.
- Escribir código limpio.
- Evitar duplicación.

---

## Fase 4 - Seguridad

Responsable:

- Security Auditor

Objetivos:

- Revisar vulnerabilidades.
- Validar permisos.
- Revisar autenticación.
- Revisar datos sensibles.

---

## Fase 5 - Calidad

Responsables:

- QA Engineer
- Testing Specialist

Objetivos:

- Ejecutar pruebas.
- Detectar errores.
- Validar funcionalidad.
- Evitar regresiones.

---

## Fase 6 - Optimización

Responsables:

- Performance Optimizer
- Refactoring Engineer

Objetivos:

- Mejorar rendimiento.
- Reducir complejidad.
- Optimizar consultas.
- Mejorar mantenibilidad.

---

## Fase 7 - Documentación

Responsable:

- Documentation Writer

Objetivos:

- Actualizar documentación.
- Registrar cambios.
- Actualizar README.
- Actualizar API.

---

## Fase 8 - Publicación

Responsables:

- Release Manager
- Git Manager

Objetivos:

- Revisar versión.
- Crear changelog.
- Preparar release.
- Verificar estabilidad.

---

# Regla General

Ningún agente debe modificar código sin haber pasado previamente por las fases de análisis y arquitectura.

Todas las respuestas y documentación deben estar en español.
